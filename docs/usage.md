# SmoothMail — 利用方法

SmoothMailは、IMAP4／SMTPでメールを受信・送信するデスクトップメールクライアントです。複数アカウントのフォルダ、メール一覧、本文を一つの画面で扱い、取得済みメールをローカルに保存します。現時点の優先動作環境はWindowsです。

## 基本操作

Windows版はZIPをすべて展開し、`launch.cmd`から起動します。`runtime/`内の本体・DLL・プラグインは一緒に保持してください。ライセンス資料は`licenses/`にあります。

展開先とは別に、ユーザーのデータ領域・設定・OS資格情報ストアを使用します。保存先、バックアップ、削除時の注意は[データの保存領域](storage.md)を参照してください。

### メールを読む

1. 左のフォルダ一覧でアカウントを展開し、フォルダを選びます。未取得のフォルダは初回に取得します。
2. 右上のメール一覧でメールを選ぶと、右下に本文を表示します。
3. 必要に応じてフィルタ、ページ番号、列見出しのソートを使います。

取得済みのフォルダを開き直すだけでは通信しません。HTMLメールも装飾せずソースを文字列で表示し、外部画像は読み込みません。

### 情報を更新する

- **F5**：全アカウントの差分更新。各フォルダの最新メール日時から1時間前までを目安に取得します。初回などは全件取得します。
- **Ctrl+F5**：全アカウントの全フォルダを同期します。取得済み本文は再利用します。
- アカウント／フォルダを右クリックすると、その対象だけを差分更新・全更新できます。
- **メール → 自動で更新**：システム設定の周期で差分更新します（既定30秒）。

重要・未読の変更やフォルダ操作、移動はローカルへ即時反映し、次の取得時にサーバへ反映します。失敗した変更は保留されます。更新後に食い違いがある場合はサーバの情報を優先します。

### アカウントを登録する

1. **設定 → アカウントの追加**を開き、メールアドレスを入力します。
2. IMAP4（受信）とSMTP（送信）のサーバ、ポート番号、アカウント名、認証方式、暗号化方式を設定します。PLAIN／LOGINではパスワードも入力します。通常はSSL/TLSまたはSTARTTLSを選んでください。
3. **接続テスト**を押します。OAuth2ではプロバイダを選び、必要な認可を外部ブラウザで行います。パスワード欄は使いません。
4. 両方の接続テストが成功し、赤い「未」が緑の「✓」になったら、**決定**で保存します。

入力を変更すると再テストが必要です。失敗したら表示されたエラーと接続設定を確認してください。暗号化に失敗しても、暗号化なしには自動で切り替わりません。

Google OAuthでは、先に**設定 → システム設定**へDesktop app用のクライアントIDと必要なシークレットを登録します。Google Cloudで同意画面・メール用スコープ `https://mail.google.com/` を設定し、テスト中のアプリでは利用アカウントをテストユーザーへ追加してください。Gmailの例はIMAP4 `imap.gmail.com:993`、SMTP `smtp.gmail.com:465`、ともにSSL/TLS・OAuth2／Googleです。

Microsoft OAuthにはpublic clientのアプリ登録（リダイレクトURI `http://localhost`）、メール用の委任権限とサーバ側のIMAP／SMTP AUTH許可が必要です。起動環境に `SMOOTHMAIL_MICROSOFT_CLIENT_ID` を設定します。Microsoftの実サービスでの動作確認は未完了です。

## 画面の見方と操作

### フォルダ一覧（左）

- アカウント、フォルダ、子フォルダをツリー表示します。太字と右の数値は子フォルダを含む未読数です。
- アカウント左のアイコンで取得中・直近の取得失敗を確認できます。
- アカウントを上下へドラッグすると並べ替えられます。
- メールやフォルダを同じアカウント内のフォルダへドラッグすると移動します。メール移動にはサーバのMOVE・UIDPLUS対応が必要です。

右クリックメニュー：

| 対象 | 操作 |
| --- | --- |
| アカウント／フォルダ | 新規フォルダ、最新の情報を取得、最新の全ての情報を取得 |
| アカウント | アカウントの編集・削除、SMTP／IMAP4のOAuthを再認可（OAuth2利用時） |
| フォルダ | 名前の変更、削除 |

新規フォルダは作成後にその場で名前を入力します。フォルダ削除はサーバへ反映される操作です。確認内容をよく読んでください。アカウント削除はローカルの登録・キャッシュ・資格情報を除去し、サーバのメールは削除しません。アカウント編集は保存後、次回の取得から適用されます。

### メール一覧（右上）

- フィルタ文字列を入力し、**検索**またはEnterでフォルダ全体を絞り込みます。件名、差出人、宛先、本文が対象です。**重要のみ**・**未読のみ**は併用できます。
- 右上に表示範囲・総件数・ページ番号を表示します。ページ番号は直接入力できます。一覧の先頭で上キー、末尾で下キーを押してもページを移れます。
- 重要・未読の記号部分をクリックすると状態を切り替えます。添付の有無も表示します。
- 件名・差出人名・差出人アドレス・日時の列見出しをクリックしてソートし、再クリックで昇順／降順を切り替えます。
- 列見出しのドラッグで列順を、境界のドラッグで列幅を変更できます。ソート・列順・列幅は次回起動時にも復元します。
- 一覧で**Alt+左／右**を押すと、前／次ページの同じ位置へ移動します。移動先の件数が少ない場合は末尾を選択します。
- フィルタ・ソート変更後も、選択中のメールのページへ移動して選択を維持します。フィルタ対象から外れた場合は選択を解除します。
- **スレッド表示**では、返信関係を件名列の開閉ボタンでたどれます。ページ外の親メールはそのページには表示しません。

### メール閲覧部（右下）

- 件名、日時、差出人、宛先と本文を表示します。日時はシステムのタイムゾーンです。アドレスやURLの非ASCII文字は赤太字で強調します。
- 添付カードをクリックするとDownloadsへ保存します。同名ファイルは上書きせず連番を付けます。
- ヘッダの▶／▼で生のヘッダを開閉します。
- 本文の対応するURLはクリックで外部ブラウザへ開きます。強調表示は安全性の保証ではないため、リンク先を確認してください。
- **Ctrl+F**で本文検索を開きます。Enter／下ボタンで次、Shift+Enter／上ボタンで前、Esc／閉じるボタンで終了します。一致箇所はピンク、現在位置は青で表示します。

各パネルの境界線をドラッグすると表示領域を調整できます。添付一覧とヘッダの境界、展開したヘッダと本文の境界も調整できます。添付のないメールでは添付一覧の境界は表示しません。

### ステータスバー・タスクトレイ

画面下部に最終更新日時、取得中のアカウント、添付の保存結果やエラーを表示します。

ウィンドウを閉じるとトレイへ格納します。トレイアイコンのダブルクリック、または右クリックの**表示**で戻し、**終了**でアプリを終了します。トレイを利用できない環境では閉じる操作で終了します。

## メニュー一覧

| メニュー | 項目・用途 |
| --- | --- |
| 編集 | 元に戻す（Ctrl+Z）、やり直す（Ctrl+Y）、フィルタ検索へ移動（Alt+F）、本文内を検索（Ctrl+F） |
| 表示 | スレッド表示の切替（Ctrl+T） |
| メール | 差分取得（F5）、全件取得（Ctrl+F5）、自動で更新、自動で既読を付ける、新規メール（Ctrl+N）、新規返信メール（Ctrl+R） |
| ツール | ダウンロード履歴（Ctrl+D） |
| 設定 | アカウントの追加、システム設定 |
| ヘルプ | このソフトウェアについて... |

「自動で既読を付ける」は選択した未読メールを既読にします。元に戻す／やり直すの対象は、手動の重要・未読変更、メール／フォルダ移動、フォルダ作成です。作成画面では入力編集が対象です。自動既読は対象外で、履歴は終了時に消えますが未同期の変更は残ります。フォルダ作成の取消では、メールのあるフォルダを削除しません。

## ダイアログ

### 新規メール・新規返信メール

フォルダを選び、新規メールまたは返信を開きます。送信元は選択アカウントで固定です。To、CC、BCC、件名、プレインテキスト本文を入力し、**送信**で送信、**保存**でサーバの下書きフォルダへ保存します。失敗時は入力を保持し、自動で再送しません。

返信の宛先はReply-Toがあればそのアドレス、なければFromです。全員への返信ではありません。空・不正なReply-Toがある場合は宛先を補完してください。返信元の件名をクリックすると元メールへ移動し、作成画面を一時的に隠します。新規メール／新規返信メールから作成中の画面を再表示できます。

### アカウントの追加・編集

[登録手順](#アカウントを登録する)に従って入力します。編集はアカウントの右クリックから開き、保存前に再度接続テストします。OAuth失効時は右クリックのプロトコル別再認可を使います。

### システム設定

1ページの表示件数（既定100）、更新の並列数（既定4）、自動更新周期（既定30秒）、Google OAuthのクライアントID・シークレットを設定し、**保存**します。**キャンセル**では変更を保存しません。シークレットはOS資格情報ストアへ保存します。

### ダウンロード履歴

元メールの件名、MIMEタイプ、保存日時、保存先、サイズを表示します。行を右クリックし、**元メッセージ...**でメールへ移動、**ファイルの保存先...**で保存フォルダを開きます。元メールが見つからなければエラーを表示します。

### このソフトウェアについて

ソフト名、バージョン、ビルド日、ソースのコミットを確認できます。左で文書を選ぶと、右にライセンス原文や変更通知を表示します。Markdownは整形して表示し、文書間のリンクで移動できます。その他の原文はプレインテキストで表示します。

資料はオフラインで閲覧できます。外部URLをクリックした場合は既定ブラウザで開きます。
