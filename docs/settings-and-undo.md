# 設定・検索・移動

- **設定 → システム設定**で1ページの件数、自動更新周期、Google OAuthのクライアント情報を保存できます。シークレットはOS資格情報ストアに保存します。
- **Alt+F**で一覧のフィルタ欄へ、**Ctrl+F**で本文検索へ移動します。本文検索はEnterで次、Shift+Enterで前、Escで閉じます。
- 一覧の端で上／下キーを押すと、前／次ページへ移ります。
- 同じアカウント内のフォルダへメールやフォルダをドラッグして移動できます。変更はローカルへ即時反映し、次の情報取得でサーバへ送ります。
- **Ctrl+Z／Ctrl+Y**で手動の重要・未読変更、移動、フォルダ作成を元に戻す／やり直せます。自動既読は対象外。履歴は終了時に消えますが、未同期の変更は保持します。
- 取得済みフォルダを開き直すだけでは通信しません。F5、Ctrl+F5、自動更新、未取得フォルダの初回表示などで取得します。

安全なメール移動にはサーバのMOVE・UIDPLUS対応が必要です。未対応の場合はエラーを表示し、保留を残します。フォルダ作成の取消では、メールのあるフォルダを削除しません。
