# アカウントの追加・編集

1. メールアドレスとSMTP／IMAP4のサーバ・認証情報を入力します。
2. **接続テスト**を押します。OAuth2の場合は、必要な認可を外部ブラウザで行います。
3. テストが成功すると、ボタンの赤い「未」が緑の「✓」に変わり、**決定**で保存できるようになります。

設定やパスワードを変更すると、接続テストは未成功へ戻ります。既存アカウントの編集でも、保存前にテストが必要です。OAuthのパスワード欄は無効になり、認可専用ボタンはありません。

Google OAuthのクライアント登録情報は、システム設定で先に用意してください。Microsoft向けの開発者設定は`docs/dev/oauth.md`を参照してください。接続テストや認可に失敗した場合は、表示されたエラーを確認して設定を修正してください。
