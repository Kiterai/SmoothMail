# 返信元への移動と境界線

仕様 `0f2945e`・`9f26a94` を反映。

- フォルダ／一覧、一覧／ビューア、展開ヘッダ／本文のドラッグ境界に明確な線を表示する。背景色の明暗に応じて白／黒を選び、暗い配色でも境界を判別できる。ヘッダ折り畳み時は従来どおりその境界を隠す。
- 返信作成画面の返信元件名を、入力不可のラベルへ変更。ホバー時に背景色が変わり、クリックまたはEnter／Spaceで元メールへ移動する。
- 返信元は作成開始時のメールを追跡し、移動・改名後も識別する。件名一致やReply-Toでは検索しない。見つからない場合は別メールへ移動せず、作成中の入力を維持してエラーを表示する。
- 移動成功時は作成画面を一時的に隠す。メニューの新規メール／新規返信メールで、同じ画面と入力を再表示できる。詳細は `spec/provisional/reply-source-navigation.md`。

境界線はQtのQPainterによる線描画で、新しい画像・外部素材は使用していない。既存Qt SDK・依存ライブラリは変更しない。

## 検証・配備

- オフラインWindows Sandbox：12 EXE、202件成功、失敗・スキップ0件。ホストCTest15対象とPython31件も成功。
- 明暗の配色と縦横のドラッグ、返信元の移動・改名・UID衝突／UIDVALIDITY変更・削除、フィルタ解除と入力保持を検証。合成GUIの画面でも境界線とラベルのホバー表示を確認した。
- 実メール・実資格情報は使わず、今回のSandboxは終了済み。既存のAUTH-01／CHECK-01の利用者確認とは別の合成回帰である。
- `build/local-run`を検証済み版へ更新。旧版は`build/local-run-before-reply-source`に保持。
- ログ・スクリーンショット・シンボル・ランタイムのSHA256一覧は`build/reply-source-check/`。Release配布物ではない。
