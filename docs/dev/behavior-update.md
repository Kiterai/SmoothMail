# 同期・フラグ操作の仕様変更（803f145）

- F5「最新の情報を取得」：全フォルダを確認し、各フォルダの最新メール日時から1時間前までを更新します。初回・日付なし・UIDVALIDITY変更時は全件取得します。
- Ctrl+F5「最新の全ての情報を取得」：全フォルダの一覧とフラグを同期します。保存済み本文は再利用します。
- 自動更新は30秒間隔の差分取得です。
- 重要/既読の変更は画面に即時反映し、ローカルに保留します。同期時にまとめて送信し、再取得後はサーバ値を優先します。送信失敗時は保留が残ります。
- 「自動で既読を付ける」は初期値オフ。新規メールはCtrl+N、返信はCtrl+Rです。
- バッジは中央揃え・記号部分のみクリック可能。スレッドの枝はタイトル列へ移動しました。

DBはv3へ非破壊移行します。旧版はv3 DBを開けないため、旧ランタイムへの単純な切戻しはできません。日付の解釈などの未指定事項は`../../spec/provisional/behavior-details.md`、内部実装は`../../agent/behavior-sync.md`を参照してください。

## 起動と検証

通常の`build/start-smoothmail.cmd`から新版を起動します。利用者によるアプリ終了後に`build/local-run`を更新し、旧ランタイムは`build/local-run-before-behavior`へ保存しました。配置42ファイルのハッシュと保存EXEとの一致を再確認済みです。

Windows Sandboxの11 EXEで137 passed / 0 failed / 0 skipped、ホストCTest15対象とPython9件が成功しました。ログと合成データの画面記録は`build/behavior-check/output-verified/`です。実メール・実アカウントの接続確認は行っていません。
