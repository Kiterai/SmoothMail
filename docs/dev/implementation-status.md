### UI仕様6f72dec: 大量メールとペジネーション

- 通常アプリを、100件単位のヘッダ取得・通常8 MiB単位の本文取得/SQLite退避・成功時のみの一括公開へ変更しました。1万件/原文合計128 MiBの一括取得制限は通常経路には適用しません。UIDVALIDITY/UID一致の本文は再利用します。単体64 MiB制限、フォルダ数/階層の保護は維持します。
- 一覧を100件単位のSQLページ取得へ変更し、ページ数/件数/番号入力、全文字列検索、重要/未読ANDフィルタ、不定進捗表示、全件対象ソート、重要/未読のUID STOREを追加しました。GUIは要約1ページと選択中の本文1通だけを保持します。ページ外の親は複製せず、スレッドはページ内で表示します。

## 外部設定・権限

- Googleのテスト用アカウントとOAuth Desktop appのクライアントIDは提供済みです。利用者自身によるブラウザ認可と、その後のトークン取得・更新・メール認証の成功確認は必要です。Microsoftのアプリ登録・認可は未提供です。通常のGoogleパスワードをIMAP/SMTPへ送信する代替方法は使いません。利用者のパスワードやトークンをチャットへ貼り付ける必要はありません。
- Safe Shell内のloopback TCPはWinError 10013で拒否されます。外部通信を無効にしたWindows Sandbox内の合成サーバーではテスト可能です。
- OS資格情報ストアの書込みテストは使い捨てのWindows Sandbox内だけで実行しています。
