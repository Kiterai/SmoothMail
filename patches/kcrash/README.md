## 経緯・変更

DIST-04で、DrKonqi探索用の絶対ビルドprefixがDLLに残ることを確認しました。
インストール先設定・`qt.conf`・DrKonqiの実行時無効化では、その文字列は除去されません。

Windowsだけで最後の「ビルド時のlibexec位置」候補を除き、その絶対定義もコンパイル対象外にします。
環境変数、実行中のEXEの隣、Qtの実行時libexec位置の探索は残します。
KCrash全体の無効化、クラッシュハンドラ・緊急保存・再起動APIの削除ではありません。
Windows以外の探索とABIは変更しません。

元prefixにしかないDrKonqiは見つからなくなります。必要なら実行時候補に正しく配置してください。
SmoothMailは独自診断を使用し、DrKonqiを製品に同梱しませんが、将来利用する場合はこの制限を再評価します。
通常起動先やQt SDKを変更せず、DLLの事後書換えや検査除外で対処しません。
