# 設定ダイアログのレイアウト

- アカウントダイアログはスクロール領域を使わず、IMAP4／SMTP／OAuthを縦に並べたグループボックスにする。
- 最上位レイアウトに`QLayout::SetFixedSize`を指定する。利用者によるサイズ変更を禁止しつつ、OAuth表示／非表示やステータス表示で必要サイズへ自動伸縮させる。
- IMAPまたはSMTPの片方でもOAuth2ならOAuthグループを表示する。両方が非OAuth2になって初めて隠す。
- 空の状態表示欄は初期状態で隠し、接続テスト開始または認証情報読込エラー時に表示する。
- 画面サイズへ一律に制限して内容を切る処理は撤去した。通常のフォームは内容に合わせて収まり、非表示OAuthの高さや伸縮用の空白を残さない。
- Qt Testでスクロール領域の不存在、サイズ変更禁止、OAuth表示時の拡大・非表示時の元サイズへの復帰、片側OAuth継続時のサイズ保持、エラー欄の表示を検証する。
