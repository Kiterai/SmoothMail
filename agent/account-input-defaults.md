# アカウント入力補助

- OAuthブロックはIMAP/SMTP共通の1欄とし、いずれかの認証方式がOAuth2の場合のみ表示する。
- メールアドレス変更時のみ既知ドメインからプロバイダを選択。未知ドメインでは既存選択を維持する。
- 旧データで両プロトコルのプロバイダが異なる場合、編集画面はOAuth2のIMAPを優先して共通欄を初期化する。保存には再度の接続テストが必要。
- 暗号化変更時のみポートを補完し、その後の手入力は保持する。編集時の既存ポートは補完より後に復元する。
- IMAPのポート補完は、なし／STARTTLS=143、SSL/TLS=993。SMTPは、なし=25、SSL/TLS=465、STARTTLS=587。
