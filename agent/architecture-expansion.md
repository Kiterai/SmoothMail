# 依存図・ソース一覧表の拡充

対象: `c18bb26`、`spec/docs.md`。旧形式の図は`architecture-generation.md`の履歴として区別する。

## 実装

- ソースファイル図は外部includeを除外し、同ディレクトリ・同basenameの`.h`／`.cpp`を統合した。ディレクトリごとのGraphviz clusterを作成し、自己依存を除去する。
- クラス図はDoxygenのmember参照とTree-sitterの構文木を併用する。戻り値・引数・ローカル変数・フィールド・関数呼出しを集約し、グローバル関数を頂点にせず、再帰を含む呼出し連鎖を固定点計算でクラスへ還元する。
- 名前空間は内部キーで保持し、ラベルからだけ除く。型別名の展開、明示型とfactory戻り値による`auto`変数の推定、メソッド宣言のみの型依存も対象とする。
- Qtの宣言／アクセスマクロ、WINAPI、ビルド文字列マクロ等は位置を変えず構文解析用に正規化する。`= {}`に対するC++文法の構文回復も回避する。表の関数引数は元ソースから切り出し、既定値等を書き換えない。
- ファイル図・クラス図は`tred`、続いて`unflatten -l 3 -f`を実行してからSVG化する。辺の種類は区別しない。
- CMake file APIから当プロジェクトのターゲット別ソースを収集し、Tree-sitterから定義クラス・定義グローバル関数・直接includeを抽出する。表は`docs/dev/architecture.md`の専用マーカー内だけを再生成する。
- 資料生成専用のPython依存は`tools/architecture-requirements.txt`へ固定した。アプリのコンパイルや依存ライブラリ構築へTree-sitterを導入しない。
- 図は全てソース・ツール出力から生成し、外部の画像素材は使用しない。利用ツールは既存のDoxygen 1.18.0／Graphviz 16.1.1と、PyPIのtree-sitter 0.25.2／tree-sitter-cpp 0.23.4。ローカル検証用依存は`build/doc-tools/python`へ配置し、システムPythonのパッケージは変更していない。

## 検証

- Python単体試験27件成功（Tree-sitter専用依存を有効化）。ペア統合、内部限定、グループ化、同名別名前空間、グローバル呼出し連鎖・再帰、Doxygen参照による補完、型別名、factory／auto、メソッド宣言、Qtマクロ、CMake file API除外条件、表の行分割とエスケープ、手書き文面の保持を確認した。
- 全プロジェクトソースを構文回復なしで解析できた。ファイル図は34頂点・縮約後49辺、クラス図は60頂点・縮約後76辺。Graphviz JSONの独立読み戻しで外部／テストの非混入と、Tree-sitterの全クラス依存の到達可能性が縮約後も保たれることを確認した。
- CMakeの実設定、Doxygen、Tree-sitter、Graphvizから4種類のDOT／SVGと表を再生成した。資料生成でアプリコンパイル・実認証・ユーザーデータの操作は行っていない。
- 配布補助CTest 12件も全件成功した。製品ZIPの通し再検証（BATCH-01）の完了を意味しない。

これは文書生成向けの静的解析であり、コンパイラと同等の意味解析や、実行時ディスパッチ・テンプレート全実体化を保証しない。オーバーロード候補の保守的集約等の限界は利用者向けの再生成説明にも明示した。
