# メール一覧と情報ダイアログ

- ページ番号は`PageNumberBox`（スピンボタンなし）。入力確定時に範囲外・整数桁あふれを補正し、左右のページ送りボタンは端で無効化する。
- バッジは`BadgeDelegate`のQPainterによる独自描画。星（輪郭／黄色単色）、丸（灰色輪郭／黒単色）、クリップを描画する。外部画像・フォントの絵文字描画は使用しない。モデルの表示文字列は状態識別に残す。
- `MailService::syncProgress`はアカウント・フォルダ・完了件数・対象件数を通知。対象件数`-1`は未確定で、UIは件数を表示しない。
- 差分取得はヘッダの厳密な日時境界とキャッシュ再利用を先に判定し、実際に本文取得が必要な件数を分母にする。対象メタデータは自動削除される一時ファイルへ退避し、本文取得は従来どおり件数・バイト数制限付きバッチ。全件取得はフォルダ全件数を分母にし、キャッシュ再利用も完了件数に含める。
- 差分対象が0件の場合も`0 / 0`を通知する。UIDVALIDITY変化・境界不明で全件へフォールバックする場合は全件の分母を使う。
- 情報ダイアログは上部ラベルの垂直サイズポリシーをFixed、ライセンスsplitterのレイアウト伸長率を1にする。

## 検証

- `build/ui-spec-check`：既存Qt 6.12.0と既存Release依存を再利用した本体・テストのビルド、通信系を除くCTest 12ターゲット成功。資格情報ストアの実書込みはopt-inせず。
- 外部ネットワーク無効のWindows Sandbox：差分の日時境界／キャッシュ除外／対象0件／全件分母、10,034件の分割取得・失敗時のキャッシュ保持を検査。通信4 passed、mainwindow 26 passed、aboutdialog 6 passed（init/cleanup込み）。ログは`build/ui-spec-guest-output`。
- ホスト制限環境の合成通信テストはタイムアウト。制限外コマンドは利用者が不許可としたため実行せず、上記Windows Sandbox内のloopbackで検証する。実サービス・実資格情報は使用しない。
