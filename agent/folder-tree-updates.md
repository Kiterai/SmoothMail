# フォルダ一覧の仕様追加（2026-11-18）

## システムフォルダと一般フォルダ

- `63db2e1`に対応。直下のシステムフォルダを指定順に並べ、一般フォルダは常設の「フォルダ」ノードへ集約する。
- 集約ノードは初期状態で折り畳む。更新・アカウント再読込・テーマ変更でも既存ノードの展開状態とスクロール位置を保持する。
- 集約ノードは実フォルダと別roleで識別し、選択・編集・ドラッグ元/先・右クリック操作の対象外とする。同名の実フォルダとは混同しない。
- 未読数は従来どおり子を含めて集計する。
- アイコンはQPainterによる独自の線画（メール、注意付きメール、鉛筆、送信、送信中、ゴミ箱、アーカイブ、フォルダ）。外部素材なし。palette変更時に再生成する。
- `build/directory-refactor`のReleaseテストを再構築し、mainwindow CTest成功。固定順、階層、集約、同名フォルダ、未読集計、空集約ノード、操作禁止、展開状態保持を追加検査した。

## フォルダ単位の読み込み表示

- `cf61278`に対応。既存のsyncProgress通知からアカウント別の処理中フォルダを追跡し、そのフォルダとアカウントへ読み込みアイコンを表示する。
- 次フォルダへ移ると元のアイコンへ戻す。同期終了（失敗・取消を含む）とアカウント削除で状態を消去し、エラー時にはアカウントのエラー表示を維持する。
- 件数通知ではツリーを再構築しない。別アカウントの同時同期とは独立して管理し、キャッシュ再公開・テーマ変更後にも状態を復元する。
- mainwindow CTest成功。複数アカウント、子フォルダ、切替、終了、エラー、モデル行を削除しないことを追加検査した。

## 推定残り時間

- `910ca96`に対応。確定件数の通知開始からQElapsedTimerで計測し、経過時間×残件数÷完了件数を10秒単位で切り上げて表示する。
- 差分取得の候補調査中（total=-1）は件数・残り時間を出さない。完了0件で予測不能な間も残り時間を出さず、全件完了・空フォルダは0秒とする。
- アカウント別に計測し、フォルダ変更・再同期・総件数変更・件数巻戻りで初期化する。同じ件数の重複通知では予測を再計算しない。
- 単位変換・境界の切上げ・大きな整数・計測状態の独立性を追加検査した。
