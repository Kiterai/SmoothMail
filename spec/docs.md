# ドキュメント整備

docs/下には人間向けのドキュメントを格納する。簡潔に読みやすさ重視。
    - docs/直下: 一般ユーザ向け
    - docs/dev/: 開発者向け

## ドキュメント一覧

以下のドキュメントを整備する。ここに記述していないドキュメントは作成しない。
開発・実装の経緯に近い内容は省き、現状における必要な情報に絞って記述する。

- docs/usage.md
    - ソフトウェア名
    - ソフトウェア概要
    - 基本操作
        - メールの閲覧方法
        - 情報の更新手順
        - アカウントの登録方法
    - UI説明
        - 各パネルの概要・機能・操作方法の説明
        - 各メニューの説明
        - 各ダイアログの概要・操作方法の説明
- docs/storage.md
    - アプリケーションが使用するデータ記録領域の説明
- docs/dev/build.md
    - ビルド前に行うべき準備・システム要件
    - デバッグビルド手順
    - リリースビルド手順
- docs/dev/test.md
    - テスト手順
- docs/dev/run.md
    - デバッグ実行手順
    - リリースビルド実行手順
- docs/dev/distribution.md
    - 最終配布物生成・検証手順
    - 配布手順
    - ライセンス注意事項
- docs/dev/architecture.md
    - 大まかな単位でのモジュール説明、構造概観、依存関係
    - 依存する外部ライブラリ・ツール一覧
    - ツールで自動生成された依存図
        - CMake GraphvizによるCMakeターゲット依存図
            - 自動テスト用ターゲットを含まない。
            - このプロジェクトに含まれるターゲットと外部ライブラリのターゲットで塗り分ける。
        - Doxygen+Graphvizによるソースファイル間依存図
            - 自動テスト用ソースコードを含まない。
            - このプロジェクトに含まれるソースファイルと外部ライブラリのソースファイルで塗り分ける。
        - Doxygen+Graphvizによるソースディレクトリ間依存図
            - 自動テスト用ソースコードを含まない。
            - 外部ライブラリを含まない。
