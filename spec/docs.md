# ドキュメント整備

docs/下には人間向けのドキュメントを格納する。簡潔に読みやすさ重視。
    - docs/直下: 一般ユーザ向け
    - docs/dev/: 開発者向け

## ドキュメント一覧

以下のドキュメントを整備する。ここに記述していないドキュメントは作成しない。
開発・実装の経緯に近い内容は省き、現状における必要な情報に絞って記述する。

    - 大まかな単位でのモジュール説明、構造概観、依存関係
    - 依存する外部ライブラリ・ツール一覧
    - ツールで自動生成された依存図
        - CMake GraphvizによるCMakeターゲット依存図
            - 自動テスト用ターゲットを含まない。
            - このプロジェクトに含まれるターゲットと外部ライブラリのターゲットで塗り分ける。
        - Doxygen+Graphvizによるソースファイル間依存図
            - 自動テスト用ソースコードを含まない。
            - 外部ライブラリを含まない。
            - ソースファイルのディレクトリでグルーピングを行う。
            - 同名のヘッダファイルとソースファイルはペアとみなし、グラフ上で同じ頂点とする。
            - `tred`による縮約を行う。依存の種類は区別しない。
            - `unflatten -l 3 -f`を適用する。
        - Doxygen+Graphvizによるソースディレクトリ間依存図
            - 自動テスト用ソースコードを含まない。
            - 外部ライブラリを含まない。
        - Doxygen+GraphvizおよびTree-sitterによるクラス間依存図
            - 自動テスト用ソースコードを含まない。
            - 外部ライブラリを含まない。
            - クラスが定義されるソースファイルのディレクトリでグルーピングを行う。
            - 戻り値、引数、内部での変数利用、内部での関数呼び出しによる依存を解析対象とする。
            - グローバル関数による依存も辿るが、グローバル関数はグラフ頂点として作成しない。クラスA→関数f→関数g→クラスB のような依存があった場合、A→Bに依存を書く。
            - 名前空間は表記を省略する。
            - `tred`による縮約を行う。依存の種類は区別しない。
            - `unflatten -l 3 -f`を適用する。
    - ツールで自動生成された表
        - 各CMakeターゲットごとのソースファイル一覧表(1ソースファイル1行)
            - ソースファイル名
            - 内部で定義されるクラス一覧
                - 表の1行内に複数行で記録。`<br>`で改行する。1クラス1行。
                - 名前空間は省略する。
            - 内部で定義されるグローバル関数一覧
                - 表の1行内に複数行で記録。`<br>`で改行する。1関数1行。
                - 名前空間、仮引数リストは省略する。
            - 依存するヘッダファイル一覧
                - 表の1行内に複数行で記録。`<br>`で改行する。1ファイル1行。
