# 返信元メールへの移動の補完事項（未承認）

- 返信元ラベルのクリックは、現在の選択メールや同じ件名、Reply-Toアドレスを検索するのではなく、返信作成開始時のメールを識別して移動する。件名が空でも返信元があれば操作できる。新規メールの空ラベルは操作しない。
- 移動先のページを開くため一覧の文字列・重要／未読フィルタを解除する。本文を確認できるよう、移動成功時は作成画面を一時的に隠してメイン画面を表示する。新規メール／新規返信メールのメニュー操作で同じ作成画面を再表示し、入力は維持する。
- 移動や改名に追従する識別ハンドルを使う。元メールの削除、UIDVALIDITY変更、接続先変更などで元の識別情報を確認できない場合は、別メールを開かずエラーを表示し、作成画面・入力を維持する。
- 移動のためだけに自動でサーバ同期は行わず、保存済みデータを参照する。操作対象のハンドルは作成画面を破棄すると解除する。
- キーボードでも返信元ラベルへフォーカスし、Enter／Spaceで移動できる。送信・下書き保存中は新しいラベル操作を受け付けない。
