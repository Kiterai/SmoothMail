# 同名LIST項目の属性統合（互換性の補完）

同名項目が複数通知された場合の詳細は承認済み仕様にないため、以下を実装上の補完として記録します。

- 名前はKIMAPがデコードした文字列の完全一致で比較し、同じ階層区切りの場合だけ統合します。独自の大文字小文字・Unicode正規化は追加しません。
- 属性は大文字小文字を区別せず和集合にします。ただし、選択可能な記述があれば`\NoSelect`を除き、すべてが選択不可なら維持します。
- `\HasChildren`と矛盾する`\HasNoChildren`・`\Noinferiors`は除きます。
- 階層区切りの矛盾は推測で解決せず、明示的なエラーで停止します。
- 重複によって安全上限を迂回させないため、LIST応答数の制限は統合前の項目数に適用します。
