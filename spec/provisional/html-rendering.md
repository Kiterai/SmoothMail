# 将来のHTMLメール表示案

[採用技術](../tech.md)にある将来のHTML表示について、旧tech.mdの設計案を退避した。以下は未承認であり、表示エンジンの正式採用や現行の実装要件を意味しない。

- 現時点ではQt WebEngine/WebViewをビルド・実行時依存に含めない。
- 将来の第一候補はQt WebEngineとするが、正式採用は別途判断する。
- メール解析結果の値モデルとレンダラーを分離し、認証情報や通信セッションを表示エンジンへ渡さない。
- 導入時には、ライセンス、外部通信遮断、能動機能制限、サンドボックス、ローカルファイルアクセス禁止、継続的なセキュリティ更新を検証する。

現在のソース表示・安全なプレインテキスト挿入の実装上の注意は[技術引継ぎ](../../agent/tech-implementation-notes.md)を参照する。HTMLレンダリング未導入を現行仕様の未完了として扱わない。
