# 803f145への追従における未指定事項（暫定）

承認済みの`spec/behavior.md`・`spec/ui.md`は変更しません。以下は実装上の補完であり、必要なら利用者の指定に合わせて変更します。

- 差分取得の「メールの時刻」は、一覧の日時と同じメールのDateヘッダを使用します。サーバ受信日時や最後に同期した時刻ではありません。
- キャッシュがない、有効な日時がない、UIDVALIDITYが変わった場合は、そのフォルダを全件取得します。
- 日付のない新着や、境界より古い日付で追加されたメール、範囲外の削除・フラグ変更は全件取得で確認します。
- 「自動で既読を付ける」の初期値はオフです。フラグバッジの直接クリックは手動のフラグ操作として扱い、自動既読との二重反転を避けます。
- 保留フラグは再起動しても保持します。送信失敗時は保留を残し、再同期で再送します。同期中の追加編集は次回送信へ残します。
