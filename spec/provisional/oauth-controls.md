# OAuth操作の暫定UI

現仕様のGoogle/Microsoft対応・失効からの復旧に必要な最小操作として、以下を暫定実装する。詳細UIは未承認のため、この文書で管理する。

- SMTP/IMAP4のOAuth2選択時、Google/Microsoftのプロバイダ選択と「OAuthで認可」を表示する。パスワード欄へのトークン貼付けは受け付けない。
- アカウント行の右クリックに、SMTP/IMAP4それぞれの「OAuthを再認可」を用意する。既存アカウントのIDやメールキャッシュを変更せず、該当する秘密情報だけを差し替える。
- 再認可は利用者の明示操作で開始し、外部ブラウザと取消可能な進捗ダイアログを使う。自動更新中の失効を理由に、勝手にブラウザを開かない。
- アプリ登録情報は開発/配布環境で設定する。未設定時は接続不能を報告し、パスワードへの降格や他プロバイダへの切替はしない。
