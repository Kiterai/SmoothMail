## 未完了と混同しないもの

- 並列更新、ヘッダ折り畳みUI、対象指定更新、日時・読み込み状態表示は実装済み。直近の隔離環境12 EXEは196件成功、失敗・スキップ0件。ホスト15対象、Python31件も成功。ただしReleaseや実サービスの検証を代替しない。[最新検証](../../docs/dev/parallel-updates-20261114.md)
- `spec/provisional/`は未承認の補完方針の置き場であり、掲載項目がすべて未実装という意味ではない。[条件付き動作](implementation-limits.md#実装済みだが条件のある動作)も参照。
- HTMLのレンダリング、macOS/Linux展開は将来方針であり、現行Windows・HTMLソース表示仕様の未実装には数えない。再起動後のUndo履歴復元も現行仕様で要求されていない。
- 古い開発記録の「通信・送信・OAuthが未実装」「依存のDebugビルドが未完了」等は、その後に解消した履歴。特にGoogleは後続の実試験成功を優先する。

## 更新方法

項目ごとに、仕様の根拠・状態・事情・完了済み範囲・次の作業／完了条件・確認資料を残す。進展時は状態と確認日を更新し、完了した項目は根拠を付けて一覧から外す。利用者のメール、資格情報、登録JSONの内容や個人環境の絶対パスは記載しない。
