# 配布バッチ移行後の通し検証

## BATCH-01: Python配布入口での製品ZIP検証

- **対象仕様:** [ビルド／バッチの分離](../tech.md)、[最終配布物](../distribution.md)、[ライセンス処理](../license-handling.md)。
- **事情:** CMakeバッチからPythonへ移行したため、旧入口で確認した製品ZIPを新入口全体の検証根拠へ流用できない。配布用通知の再確認と本体・対応ソースのcommit一致が必要となる。
- **完了範囲:** Pythonの配布・Release配置・原本収集・ライセンス生成入口。ビルド処理はCMakeのまま。単体試験と既存ネイティブ監査試験、実バイナリのRelease配置・CRT検証。
- **未完了範囲:** 同一commitの本体・対応ソース・再確認済み配布通知を用いた、新しい標準入口での製品ZIP生成から独立展開・SDK未導入環境での実行・DLL差替えまでの通し再検証。通知草案を自動承認しない。
- **完了条件:** 新入口で生成した最終ZIPについて、ハッシュ・通知／ソース対応・個人情報／Debug非混入、クリーン環境での実行、改変DLL差替えを確認し、根拠を`agent/`に記録する。
