# 配布バッチ移行後の通し検証

## BATCH-01: Python配布入口での製品ZIP検証

- **対象仕様:** [ビルド／バッチの分離](../tech.md)、[最終配布物](../distribution.md)、[ライセンス処理](../license-handling.md)。
- **事情:** ビルド／配布入口と監査タイミングを変更したため、旧入口で確認した製品ZIPを新入口全体の検証根拠へ流用できない。新しい実`.env`設定・依存取得を含む通し検証が必要となる。
- **完了範囲:** Pythonの配布・配置・原本収集・通知生成入口、CMakeのDebug／Release短縮入口、生成後に配布担当者が監査する手順。ビルド処理はCMakeのまま。旧移行時の単体試験・配布補助CTest・実バイナリ配置／CRT検証・証拠収集・23ソースアーカイブ検査は[移行記録](../../agent/python-batch-migration.md)、新入口の個別試験・実configureは[単純化の記録](../../agent/build-workflow-simplification.md)を参照する。
- **未完了範囲:** clean cloneと`.env`だけからのDebug／Release・配布生成全体、新しい標準入口での製品ZIPの独立展開・SDK未導入環境での実行・DLL差替えまでの通し再検証。生成は法的監査・公開承認を代替しない。
- **完了条件:** 新入口で生成した最終ZIPについて、ハッシュ・通知／ソース対応・個人情報／Debug非混入、クリーン環境での実行、改変DLL差替えを確認し、根拠を`agent/`に記録する。
