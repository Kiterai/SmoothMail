## UI仕様

画面構成は以下とする。

メインウィンドウ 左右2分割

- ウィンドウ上部: メニュー部
- 左ペイン: フォルダ一覧部
- 右ペイン: メールビューア、上下2分割
    - 上側: メール一覧部
    - 下側: メール閲覧部
- ウィンドウ下部: ステータスバー

ダイアログ
- 新規メール
- アカウントの追加
- ダウンロード履歴

その他
- タスクトレイアイコン

### メニュー部

- 編集
    - 元に戻す (Ctrl+Z)
    - やり直し (Ctrl+Y)
    - フィルタ検索 (Alt+F)
    - 本文内を検索 (Ctrl+F)
- 表示
    - スレッド表示 (チェックボックス項目) (Ctrl+T)
- メール
    - 最新の情報を取得(F5)
    - 最新の全ての情報を取得(Ctrl+F5)
    - 自動で更新 (チェックボックス項目)
    - 自動で既読を付ける (チェックボックス項目)
    - (仕切り線)
    - 新規メール (Ctrl+N)
    - 新規返信メール (Ctrl+R)
- ツール
    - ダウンロード履歴 (Ctrl+D)
- 設定
    - アカウントの追加
    - システム設定

### フォルダ一覧部

ツリー型UI。
- 登録アカウント > フォルダ > 子フォルダ ... の順の構造で表示。
- 未読のあるフォルダ/アカウントは未読数を名前の右に表示。これには子フォルダも含む。
- 未読のあるフォルダ/アカウントは名前を太字にして強調表示。
- データ更新中はアカウントの左に読み込み中のアイコンを表示。
- アカウントをドラッグすると上下の並び替え可。
- 直近のメールデータ読み込みに失敗した場合、エラーアイコンを表示。

例:
- foo@example.com (23)
    - Inbox (10)
    - Sent
    - Trash
    - FolderA (5)
    - FolderB (8)
        - FolderB1
        - FolderB2(8)
- (読み込み中アイコン) bar@example.com (2)
    - Inbox (2)
    - Sent
    - Trash
- (エラーアイコン) baz@example.com
    - Inbox
    - Sent
    - Trash

アカウント項目の右クリックメニュー:
- 新規フォルダ → 新しい空の子フォルダを作成する。作成後、即座にリスト上で名前を入力するUIを表示。
- アカウントの編集 → 登録されているアカウントの設定を編集する。
- アカウントの削除 → 登録されているアカウントを削除する。警告ダイアログを伴う。

フォルダ項目の右クリックメニュー:
- 新規フォルダ → 新しい空の子フォルダを作成する。作成後、即座にリスト上で名前を入力するUIを表示。
- 名前の変更 → フォルダ名を変更する。リストUI上に入力UIを表示。
- 削除 → フォルダを削除する。警告ダイアログを伴う。

フォルダをフォルダにドラッグアンドドロップした場合、フォルダがドロップ先のフォルダ内に移動。

### メール一覧部

上部に1行のフィルタ/ペジネーションUI。
メイン部はマルチカラムリスト型UI+一部ツリー型UI。

メール一覧はペジネーションし、設定で指定した件数を1ページとする。

フィルタ/ペジネーションUIの内容は以下。
- 左寄せ
    - フィルタ文字列入力欄
        - プレースホルダ表示「フィルタ文字列...」
        - メニューの「フィルタ検索」からフォーカスが移る
    - 「検索」ボタン → フィルタ文字列によるフィルタを適用。
    - 「重要のみ」チェックボックス → Flaggedのメールのみを表示。
    - 「未読のみ」チェックボックス → 未読のメールのみを表示。
    - プログレスバー: フィルタ適用処理で時間がかかる際に経過を表示。
- 右寄せ
    - (表示開始インデックス) - (表示終了インデックス) / (総件数)件 の表示
        - 例: 101 - 200 / 234件
    - (ページ番号) / (総ページ数) の表示
        - ページ番号は入力可能。数値入力ボックスUI。
        - 総ページ数が1の場合、ページ番号入力はグレーアウト。

提供するカラムは以下。
- バッジ表示(重要マーク) → IMAP4のFlaggedに対応
    - クリックで切り替え可能
- バッジ表示(未読)
    - クリックで切り替え可能
- バッジ表示(添付あり)
- メールタイトル
- 差出人名
    - 無い場合は空
- 差出人アドレス
- 日時
    - 形式: YYYY/MM/DD hh:mm (タイムゾーン略語)

バッジ表示部はアイコンをカラムの中央揃えとし、クリック判定はアイコン部分のみとする。また、バッジ表示部のカラム幅はカラム名が入る最小とする。

「自動で既読を付ける」の場合、未読メールは選択しただけで未読が外される。

カラムをクリックした場合、そのカラムでソートされる(バッジ表示を除く)。再度クリックすると昇順/降順が入れ替わる。

メール項目を特定のフォルダにドラッグアンドドロップした場合、そのフォルダにメールが移動。

リストUIの一番上にいる状態で上キーを押した場合、前ページの一番下へ飛ぶ。
リストUIの一番下にいる状態で下キーを押した場合、次ページの一番上へ飛ぶ。

Message-ID、In-Reply-To、Referencesによる返信ツリーが存在する かつ 「スレッド表示」になっている 場合、その部分の項目は[+]アイコンによる折り畳みUIでまとめて表示される。Reply-Toは返信先アドレスを示すヘッダであり、ツリー構築には使用しない。返信関係の判定はbehavior.mdに従う。
分岐が存在しない場合、1階層で表示される。分岐が存在する場合、階層が深まる。

例:
- 通常メール1
- 通常メール2
- [+] スレッド元メール
    - 返信1
    - 返信2
    - [+] 返信3
        - [+] 返信4-A
            - 返信4-A-1
            - 返信4-A-2
            - 返信4-A-3
        - [+] 返信4-B
            - 返信4-B-1
            - 返信4-B-2

分岐UIは「メールタイトル」カラムに入れる。

### メールビューア

プレインテキストで表示。

- (仕切り線) メール一覧部との境界ドラッグUI
- 基本情報表示
    - メールタイトル
    - 日時
    - 差出人名
    - 差出人アドレス
    - 宛先
- 添付ファイル一覧
- メールヘッダ展開ボタン (仕切り線)
- (仕切り線) メールヘッダとメールコンテンツの境界ドラッグUI
- メールコンテンツ
- 検索バー(通常非表示)
    - (左寄せ) n / m 件
    - (右寄せ) 検索文字列入力欄、上アイコンボタン(前の結果)、下アイコンボタン(次の結果)、閉じるアイコンボタン

基本情報表示: 改行含めて以下の形式で表示する。
件名: [メールタイトル]
日時: [日時]
差出人: [差出人名義] ( [差出人アドレス] ) 宛先: [宛先アドレス]

- UI文字列は通常の黒字、値は黒太字で表示。
- 値が空の際、灰色字で (空) と表示。
- メールアドレスに非ASCII文字が含まれる場合、赤太字で表示。
- 日時は YYYY/MM/DD (曜日) HH:mm:ss (タイムゾーン略語) の表記。

添付ファイル一覧: 存在する場合、カード型リストUIで表示。アイコン+ファイル名。
クリックするとユーザディレクトリ/Downloads下にダウンロード。

メールヘッダ: メールのヘッダ情報をフル表示。折り畳みUIに収納。通常時は格納状態。
- メールヘッダ展開ボタン: 小さいフォント(他のUI文字の2/3)で表示。輪郭なし。マウスオーバーで背景色が変わる。仕切り線と同じ行に表示。折り畳みアイコンは+/-の形式。

メールコンテンツ:
- text/plainの場合: プレインテキストで表示。URLのみクリック可能なリンク(青文字)に変換。
    - URLに非ASCIIコードが含まれる場合、その個所を赤太文字で表示。
- text/htmlの場合: ソースコードをプレインテキストとして表示。その他はtext/plainと同様。
- multipartの場合: 各partをプレインテキストとして表示。その他はtext/plainと同様。

検索バー
- メニューの「本文内を検索」で出現。
- 閉じるアイコンボタンを押下、またはEscキーで非表示。
- n / m 件 表示に本文内の検索結果件数と現在の検索位置を表示する。
- 下アイコンボタン、または検索文字列入力欄にフォーカスがある状態でEnterにより次の結果へ飛ぶ。
- 上アイコンボタン、または検索文字列入力欄にフォーカスがある状態でShift+Enterにより前の結果へ飛ぶ。
- 検索ヒットした文字列は全てピンク背景色でマーク。現在のカーソルがあるヒット文字列は青背景色。
- 検索ヒットした文字列はメールコンテンツ画面での位置が中央に来るようにスクロール。コンテンツ端にあって中央への調整が不可の場合は可能な範囲でスクロール。

その他
- 読み込み中の場合はメールコンテンツ欄に「読み込み中...」の表示。
- 読み込みに失敗した場合はメールコンテンツ欄に「読み込みに失敗しました」の表示。

### ステータスバー

- 最終更新表示
    - 最終更新: YYYY/MM/DD hh:mm:ss (xx前) の形式で表示。
    - xx前の部分は単位付きで現在時刻との差を表示。(例: 12分前、2時間前) 1分前未満の場合、<1分前 の表示。
- 更新中表示
    - 現在データを読み込んでいるアカウントを表示する。
    - hoge@example.com のデータを取得中... の形式。
- ダウンロード表示
    - ダウンロード中のファイル名を表示。
        - (ファイル名) をダウンロード中... の形式。
    - ダウンロード終了時に保存先を表示。
        - (保存先フルパス) に保存しました の形式。

### 新規メールダイアログ

メニューの「新規メール」「新規返信メール」で出現。

- "送信"ボタン: メールの送信。
- "保存"ボタン: メールの下書きフォルダへの保存。
- "件名"入力: メールタイトルを入力。
- 送信元: 送信元メールアドレス。手入力不可。
- "宛先(To)"入力: 宛先メールアドレスを入力。
- "CC"入力: CC先メールアドレスを入力。
- "BCC"入力: BCC先メールアドレスを入力。
- 返信元メール: 返信対象メールの件名を表示。手入力不可。新規メールの場合は空。Reply-Toヘッダとは区別する。
- 本文入力: メール本文をプレインテキストで入力。

新規メールの場合:
- 現在選択しているフォルダのアカウントのアドレスが送信元として自動でセット。

新規返信メールの場合:
- 現在選択しているフォルダのアカウントのアドレスが送信元として自動でセット。
- 現在選択しているメールが返信元メールとして自動でセット。
- 宛先(To)は返信元メールのReply-Toがあればそのアドレス一覧、なければFromのアドレス一覧を自動でセット。返信関係を示すヘッダの生成はbehavior.mdに従う。
- 現在選択しているメールの件名頭に"Re: "を付けた文字列が件名として自動でセット。

### アカウントの追加

メニューの「アカウントの追加」で出現。
以下の入力欄を持つ。

- メールアドレス
- IMAP4
    - サーバ
    - ポート番号
    - アカウント名
    - パスワード
    - 認証方式: 以下の選択肢から選択
        - PLAIN
        - LOGIN
        - OAuth2
    - 暗号化: 以下の選択肢から選択
        - なし
        - SSL/TLS
        - STARTTLS
- SMTP
    - サーバ
    - ポート番号
    - アカウント名
    - パスワード
    - 認証方式: 以下の選択肢から選択
        - PLAIN
        - LOGIN
        - OAuth2
    - 暗号化: 以下の選択肢から選択
        - なし
        - SSL/TLS
        - STARTTLS
- "接続テスト"ボタン
    - 太文字で表示
    - 接続テスト未成功: "接続テスト: 未" の表示。「未」は赤文字
    - 接続テスト成功済: "接続テスト: ✓" の表示。「✓」は緑文字
- "決定"ボタン

認証方式でOAuth2が選択されている場合、パスワード入力はグレーアウトする。

接続テストボタン→指定の設定でメールサーバとの接続テスト。ダイアログで状態を報告。OAuth認証もここで行う。
- 問題がない場合: 接続に成功しました。
- SMTPに問題がある場合: SMTP接続に失敗しました。(エラーメッセージ)
- IMAP4に問題がある場合: IMAP4接続に失敗しました。(エラーメッセージ)

決定ボタン: 接続テスト未成功の場合、グレーアウト

### アカウントの編集

アカウントを右クリック→アカウントの編集 で出現。
基本的に アカウントの追加ダイアログ に同じ。

### ダウンロード履歴

過去の添付ファイルダウンロード履歴を表示。
マルチカラムリストUI。

表示項目
- 元メッセージ: 元メッセージの件名を表示。
- MIMEタイプ: ファイルのMIME Typeを表示。
- 保存日: YYYY/MM/DD hh:mm 形式で表示。
- 保存パス: 保存場所を絶対パスで表示。
- サイズ: サイズをSI接頭辞付きバイト数で表示。

各項目右クリックで以下のメニュー
- 元メッセージ... → 添付ファイルの元メッセージへジャンプ
- ファイルの保存先... → 保存先パスのディレクトリを環境のファイラー(Windowsの場合エクスプローラ)で開く

### システム設定ダイアログ

メニューの「システム設定」で表示。

- 表示設定
    - 1ページに表示する件数: 数値入力欄、規定値100
- 自動更新設定
    - 更新周期(秒) : 数値入力欄、既定値30
- GMail OAuth設定
    - OAuth クライアントID : 文字列入力欄
    - OAuth シークレット : 文字列入力欄
- ボタンUI(1行)
    - 保存ボタン : 設定を保存する。変更がない場合グレーアウト
    - キャンセルボタン : 設定を保存せず終わる。変更があった場合確認ダイアログを表示

### タスクトレイアイコン

タスクトレイにアイコンを表示する。

クリック: ウィンドウを表示する。
右クリックメニュー:
- 表示: ウィンドウを表示する。
- 終了: アプリを終了する。
