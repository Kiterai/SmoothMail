- Git

## ビルド方針

- Qt6, CMake, Pythonはビルド作業者が手動で導入するものとする。
- バイナリのビルド工程は一貫してCMakeで行う。
    - 内部でvcpkg, Ninjaの利用を許容する。ただしCMakeから内部で収集することとし、ビルド作業者にはその導入の責務を持たせない。
    - ビルド処理には一貫してPythonを用いない。ただし、外部ライブラリがそのビルド処理中に内部で使うものについては許容する。
- 最終配布物の構成、ドキュメントの生成、ライセンス記述の生成など、ビルド以外のバッチ処理はPythonで行う。
    - 開発プラットフォームに依存するシェルスクリプトを用いない。(例: Windowsでしか使えないcmdやPowerShellなど)
    - ビルド/テストおよびそれに必要な準備以外のバッチ処理には一貫してCMakeを用いない。
