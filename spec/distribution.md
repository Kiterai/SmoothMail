# 配布形態

## 共通注意事項

- 最終配布物にビルド作業者の個人情報・PC内情報が含まれないようにする。
- 指定プラットフォーム向けの最終配布物はリポジトリからコマンド一行で生成できるようにする。
    - ビルド→必要ファイルの収集→圧縮等まで行えるようにする。
    - 以下に示す基本ツール・ライブラリの準備について、ビルド者の責務とすることを許容。
        - CMake
        - Git
        - Qt
        - Python
        - 各プラットフォーム向けコンパイラ/開発SDK
    - Pythonについては、技術的に不自然のない範囲で利用を最小限に抑える。依存ライブラリからの間接的利用のみを許容し、このプロジェクトに直接含まれるバッチ処理等からはPythonを排除する。

## プラットフォーム別

- Windowsの場合
    - 単体で運搬して展開・実行可能なzip形式で配布する。
    - 展開後はexeファイルから起動。
    - MSVC CRTは、必要なRelease DLLを改変せずZIPへ同梱する。以下は配布作業担当者の責務とし、配布手順の注意事項へ明記する。
        - MSVC 2022の正当な利用と適用条件の遵守。
        - ダウンロードページにおいて、このソフトウェアをダウンロードした時点で同梱するMSVC CRTの利用許諾条件に同意したとみなす旨を明らかにユーザの目につく個所に表示すること。

## ライセンス処理

- Qtはオープンソースライセンスで用いる。
- ソースコードはバイナリ配布と同じページで別途配布する。
- バイナリ配布に同梱するモジュールに関連して必要となるライセンス記述は以下のように提供する。
    - 配布ZIP内にlicensesディレクトリを配置し、その内部にライセンス記述ファイルを配置する。
    - ダイアログ表示に適宜まとめる。
        - 元ファイルにおいてMarkdownファイルであるものはMarkdownを解釈して表示し、プレインテキストファイルであるものはプレインテキストで表示する。Markdown間のリンクはリンクとしてクリックで辿れるようにする。
- ライセンス記述ファイルは以下のように管理する。
    - リポジトリ内にlicensesディレクトリを配置し、その内部でテキストを管理。
        - filename.md の形式で英語で記述し、これを正版とする。filename.ja.md の形式で日本語訳版を用意する。
        - 正版英語文書において既存ライセンスに関わる記述を行う場合、原文に倣った記述や引用にする。
        - 日本語版文書の記述は、敬体ではなく常体にする。また、漢語を基調とした固めの表現にする。(例: この文書は→当文書は)
        - 開発者・実装者の経緯や技術的事情に近い内容は省き、ライセンス上通知が必須な本質的情報に記述を絞る。
    - 共通事項についてはlicenses/common下に配置。
    - 配布する版(プラットフォームバージョン)に依存する事項についてはlicenses/editions/(名称)/の下に配置。
    - licensesディレクトリ下の記述ファイルは最終テキストではなくテンプレートとし、以下の情報については.envファイル(Git管理外)で指定して差し替え可能な変数とする。なお、記述例としての.env.exampleファイルは用意しGitで管理する。
        - ソフトウェア名称
        - 配布URL
        - ビルドバージョン情報
    - 配布版作成時には対応する版・ビルドに応じたライセンス文言をスクリプトで生成しまとめる。
    - テンプレートからの生成に際し、2行以上の空白行は1行の空白行にまとめる。これは文面内容の改変としては扱わない。
- 所定の必要なファイルの正当な配布・公開については配布作業者の責務とする。
