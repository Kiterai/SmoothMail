# 配布形態

## 共通注意事項

- 最終配布物にビルド作業者の個人情報・PC内情報が含まれないようにする。
- 指定プラットフォーム向けの最終配布物はリポジトリからコマンド一行で生成できるようにする。
    - ビルド→必要ファイルの収集→圧縮等まで行えるようにする。
    - 以下に示す基本ツール・ライブラリの準備について、ビルド者の責務とすることを許容。
        - CMake
        - Git
        - Qt
        - Python
        - 各プラットフォーム向けコンパイラ/開発SDK
    - Pythonについては、技術的に不自然のない範囲で利用を最小限に抑える。依存ライブラリからの間接的利用のみを許容し、このプロジェクトに直接含まれるバッチ処理等からはPythonを排除する。
- ライセンス的処理については、[license-handling.md](./license-handling.md)に基づいて注意深く行う。

## プラットフォーム別

- Windowsの場合
    - 単体で運搬して展開・実行可能なzip形式で配布する。
    - ZIPファイル内は以下のようなディレクトリ構造にする。
        - ライセンス情報ディレクトリ
        - runtimeディレクトリ: 必要ランタイム
            - DLL群など
            - Smoothmail.exe 本体
        - README.md : docs/usage.md と同内容
        - launch.cmd : runtimeディレクトリ内にある本体を呼び出す軽量なランチャー
    - MSVC CRTは、必要なRelease DLLを改変せずZIPへ同梱する。
